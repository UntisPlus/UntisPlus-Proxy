UntisPlus ProxyAdmin Console

Sign in to Admin

Use your Untis username and 6-digit OTP code. After sign-in you’ll enter the guided dashboard for proxy setup, schools, users, permissions, and notifications.

Authentication uses the same getUserData2017 flow as the app. Admin access is required for the dashboard.
  1. On a fresh install, the first successful non-anonymous login can claim admin access.
  2. You’ll be guided through: proxy/real client IP → add school → first admin/user → permission groups/roles → more users → notifications.
